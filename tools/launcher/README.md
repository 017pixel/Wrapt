# Wrapt Launcher

Eigenständige Tauri-2-App für den lokalen Betrieb des Wrapt-Servers. Das Projekt liegt
außerhalb der pnpm-Workspaces und verwendet npm nur für die Tauri-CLI.

Voraussetzungen, Build und Bedienung stehen in
[`docs/installation.md`](../../docs/installation.md#lokaler-betrieb-mit-launcher-macoswindows).
