# Wrapt Plugin-Beispiele

Dieser Ordner ist die lokale Beta-Quelle des Plugin-Stores. Jede der zehn
Unterordner ist ein vollständiges, bewusst kleines Beispielpaket mit
`extension.json`, `plugin.json` und einem UI-Entrypoint.

Die Pakete sind als Startpunkte gedacht: Im Bereich Plugins kann ein Beispiel
in einen eigenen Draft übernommen, im Maker verändert und anschließend lokal
veröffentlicht werden.
