# Mein erstes Plugin

Eine erste eigene Wrapt-Seite mit einem Hello-World-Text als bereinigtem HTML.

- **Slug:** `mein-plugin`
- **Route:** `/plugins/tool/mein-plugin` (sichtbare Werkzeugseite in der Sidebar)
- **Inhaltsmodus:** HTML (durch DOMPurify bereinigt, keine freien Scripts)
- **Icon:** `folder` (kontrolliertes Codewort aus der Wrapt-Icon-Registry)
- **Funktion:** „Begrüßung kopieren" (`copy-text`) über die Host-Aktionsschicht
- **Permissions:** keine · **Orbit:** nicht aktiviert · **Iframe:** keiner

Das Paket ist Teil der lokalen Beta-Katalog-Struktur unter `extensions/plugins/`
und erscheint nach der Installation unter Plugins → Eigene Plugins.
