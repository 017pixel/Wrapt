# Changelog

Die Änderungen an Wrapt, nach Version geordnet. Öffne einen Eintrag, um die Notizen zu sehen, oder filtere nach Begriff und Änderungstyp.

Die Einträge stammen aus der `CHANGELOG.md` dieses Builds. Versionen, die noch nicht im Changelog auf `master` stehen, tragen die Markierung **Arbeitsstand**. So bleibt sichtbar, welche Änderungen bereits im öffentlichen Quellstand liegen.

Zur versionierten [CHANGELOG.md auf GitHub](https://github.com/017pixel/Wrapt/blob/master/CHANGELOG.md).
